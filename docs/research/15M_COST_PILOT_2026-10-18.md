# Native 15-minute paths and cost sensitivity

Date: 2026-10-18. Status: offline pilot; no predictive edge or production change.

This continues the four-product research pilot on
`codex/trade-hypothesis-evaluation`. The owner's other session retains the
year-long archive pull, same-coin matched controls, and production label work.
This work does not read or write that shared archive or its analysis scripts.

## What changed

- Backfilled 36,880 native Coinbase 15-minute candles for BTC, ETH, SOL, and
  DOGE, with separate cached response files and source granularity metadata.
- Kept the original 4,410 hourly decisions from 25,236 transitions, the same
  source capture cutoff, next-hour entry, 49-hour geometry lookback, and hourly
  ATR. Only the future path resolution changes. Next-hour entry is a different
  delay policy, not a guarantee of more conservative results than signal-price
  entry.
- Added real 15m outcomes and a fixed-cohort cost grid: 0, 20, 50, 90, and
  120 basis points **round trip**. Each is an assumed total fee/slippage cost
  expressed as a flat percentage of entry notional. The script does not claim
  these are the owner's actual fees or simulate a changing fee schedule.
- Kept action-dependent geometry cohorts separate from the fixed-cohort cost
  results, because increasing costs can move a decision to NO_TRADE.

The aggregate with input and source-report hashes is
[`resolution-cost-pilot-summary.json`](resolution-cost-pilot-summary.json).
The complete report and gross per-decision ledger are in the ignored
`.runtime/research/resolution-cost-grid-final/` directory in this worktree.

## Resolution check

There were no hourly-versus-15m entry-open disagreements. Among paired 1h/4h/
12h/24h horizons, close returns, MFE, and MAE agree exactly between the two
native resolutions. Known target/stop orderings do not flip; some formerly
ambiguous orderings become observable.

| Horizon | Paired decisions | Hourly ambiguous | Still ambiguous at 15m |
|---|---:|---:|---:|
| 1h | 4,406 | 32 | 5 |
| 4h | 4,400 | 56 | 6 |
| 12h | 4,378 | 65 | 7 |
| 24h | 4,354 | 65 | 8 |

These ambiguity counts concern +1 ATR versus -1 ATR boundaries. At 4h, finer
bars resolve 29 of the 56 ambiguous cases as target first and 21 as stop first.
The six remaining cases are preserved as ambiguous. Structural target/stop
paths are also compared separately; the 4,397 valid paired structural paths
have unchanged first-touch classifications, with no ambiguous cases at 4h.
Bucket start times are not presented as exact hit timestamps.

## Fixed test-cohort cost grid

The chronological test split has 820 decisions, with measurable outcomes for
816 at 15m, 810 at 4h, and 764 at 24h. Every cost scenario uses these same
decisions at its respective horizon; missing future bars are not late-filled.

| Assumed round-trip cost | Mean 15m return | Mean 4h return | Mean 24h return |
|---|---:|---:|---:|
| 0.00% (gross) | +0.0100% | -0.0154% | -0.2212% |
| 0.20% | -0.1900% | -0.2154% | -0.4212% |
| 0.50% | -0.4900% | -0.5154% | -0.7212% |
| 0.90% | -0.8900% | -0.9154% | -1.1212% |
| 1.20% | -1.1900% | -1.2154% | -1.4212% |

At 0.90%, only 6 of 816 measured 15m outcomes finish positive after the assumed
cost. The median 15m MFE is 0.193 ATR and MAE is -0.202 ATR; the assumed cost
alone is a median 1.322 ATR. Cost in ATR differs across volatility cohorts,
which is why the report also retains raw percentage returns and unchanged
fixed cohorts.

These are directional fixed-horizon forward returns across all eligible test
decisions, not executed strategy P&L or matched-control excess. Down hypotheses
are analytical short directions; no borrow, funding, account availability,
stop-limit execution, or actual liquidity is modeled. A finer outcome path
does not establish predictive value. Subtracting the same flat cost from both
signal and matched-control returns leaves their excess-return difference
unchanged; assessing a strategy's break-even cost requires its own gross
returns and execution assumptions.

Calendar-week summaries use ISO weeks in UTC. Exploratory weekly-bootstrap
intervals are withheld below 12 observed weeks. Train/validation/test contain
9/4/3 weeks here, so those intervals remain null; thousands of overlapping
decisions do not become independent observations. No thresholds or cost
scenarios were selected for deployment.

## Reproduce

```powershell
python scripts/backfill_research_candles.py --input .runtime/research/production-2026-10-18.jsonl.gz --output .runtime/research/pilot-coinbase-15m.jsonl.gz --products BTC-USD ETH-USD SOL-USD DOGE-USD --cache-dir .runtime/research/coinbase-15m-raw --granularity 900
python scripts/evaluate_resolution_costs.py --hourly-input .runtime/research/pilot-coinbase.jsonl.gz --fine-input .runtime/research/pilot-coinbase-15m.jsonl.gz --output-dir .runtime/research/resolution-cost-grid-final --round-trip-bps 0 20 50 90 120
```

The backfiller remains sequential, pauses 350ms after successful uncached
requests, and backs off transient errors. Cache keys separate 15m from hourly
responses. Output paths refuse overwrite. Both input exports must contain
identical selected signal records and the same source capture cutoff. Hourly
feature loading refuses a 15m export; future measurement explicitly requires
the specified path resolution. Entry-open disagreement invalidates fine-path
outcomes rather than averaging prices.

This is scoped to the original four-coin pilot. The tools accept explicit
additional products but no full-universe 15m pull was launched. Extending the
same frozen cohorts through an archive adapter belongs in a separate run once
the other session's data and matching contract are available.
